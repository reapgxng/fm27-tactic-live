# FM27 TACTIC INTELLIGENCE

Öffentliche, grafische Sammlung der besten Ergebnisse des FM27 Auto Optimizers.

**Website (nach Aktivierung von GitHub Pages):** https://reapgxng.github.io/fm27-tactic-live/

**Einzelne Taktik:** https://reapgxng.github.io/fm27-tactic-live/?t=T00003

## Aktueller Datenstand

Die ersten fünf Kandidaten stammen aus den vom Nutzer exportierten A/B-Spielen vom 14. November 2026. Die Seite zeigt IP/OOP-Positionen, Rollen, Duties, Teamanweisungen und die simulierten Ergebnisse. Zunächst werden manche Anweisungen als interne IDs dargestellt; der lokale Publisher aktualisiert sie mit Bezeichnungen aus dem FM Tactics Lab Katalog.

**Stärkere/gleich starke/schwächere Gegner** sind synthetische Gegnerattribute und keine realen Vereinsmannschaften. Die bisherige Stichprobe beträgt bei vollständig getesteten Varianten 60 Matches (20 pro Gegnerklasse).

## GitHub Pages aktivieren

Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.

## Automatische Aktualisierung

Lokal den bereitgestellten Auto-Publisher starten, die SQLite-Datenbank des Optimizers auswählen und in GitHub authentifizieren. Das Skript schiebt ein bereinigtes öffentliches Datenarchiv in dieses Repository. Die Daten werden nicht durch ChatGPT im Hintergrund abgerufen oder aktualisiert.
